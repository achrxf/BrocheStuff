BrocheStuff 2.2 - information for the IT department
=====================================================

WHAT IT IS
A tool-sheet and tool-crib program for the CNC workshop (machines, articles,
tool lists printed on A4, tool and holder stock). Written by Achraf El
Ghaffouli. Built with Neutralinojs 5.4 (open source, MIT licence:
https://neutralino.js.org) which shows the program in a window using the
Microsoft Edge WebView2 component already part of Windows 10/11.

DOWNLOADS
  BrocheStuff-Setup.exe     installer (NSIS 3, 64-bit, per-user, not code-signed)
  BrocheStuff-Windows.zip   the same program without installer (portable)
Installed files: BrocheStuff.exe (the Neutralinojs 5.4.0 runtime, unchanged
except for the icon and version information), resources.neu (the program
itself, HTML / JavaScript, readable), README.txt, FOR_IT.txt, Uninstall.exe.
SHA256SUMS.txt lists the checksums of the installed files and
SHA256SUMS-downloads.txt those of the two downloads.

INSTALLATION
- Installs for the current user only, in %LOCALAPPDATA%\Programs\BrocheStuff.
  No administrator rights, no Windows service, no driver, no startup entry,
  no scheduled task.
- It creates a Start menu shortcut, an optional desktop shortcut, and the
  usual uninstall entry for the current user
  (HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\BrocheStuff and
  HKCU\Software\BrocheStuff\InstallDir). Nothing in HKLM.
- Silent install: BrocheStuff-Setup.exe /S   (optional /D=C:\path as the last
  argument). Silent uninstall: "%LOCALAPPDATA%\Programs\BrocheStuff\Uninstall.exe" /S
- Uninstalling removes the program, shortcuts and registry entries; the data
  folder is kept.

NETWORK
- The program makes NO internet connection: no update check, no telemetry, no
  analytics, no account, no licence server, no external fonts or scripts
  (everything is inside resources.neu).
- The page enforces a Content-Security-Policy that only allows the program's own
  local origin ("connect-src 'self'"), so it cannot reach any other address.
- To show its window, the runtime opens a local web server bound to
  127.0.0.1 only (loopback, random free port). It is not reachable from the
  network. Access to its file functions needs a one-time secret token that only
  the program's own window receives ("tokenSecurity": "one-time").
- The Windows firewall should not ask anything, because nothing listens on the
  network.

ACCOUNTS
- Every person signs in with a name (or code) and a password; the admin creates
  the accounts and gives each one a service. First sign-in: admin / admin, to
  be changed by the admin.
- Passwords are never stored in clear: PBKDF2-SHA256, 150,000 iterations,
  random salt per account (Web Crypto API). 5 wrong tries = 30 s wait.
  Sign-ins are logged (name, PC name, result) in users.json.
- Optional automatic sign-out after inactivity (set by the admin).
- Forgotten admin password: an empty file named reset-admin.txt in the data
  folder resets the "admin" account to admin / admin at the next start (needs
  write access to that folder, so it is in IT's hands).

SHARED DATA FOLDER
- By default the data stay on the PC (Documents\BrocheStuff). The admin can
  choose another folder, for example a network share (\\server\BrocheStuff),
  the same on every PC. The users need read/write access to that folder only.
- Saves use a short lock (a "data.lock" folder) so one PC writes at a time;
  each PC merges the other PCs' changes before writing (stock moves are added,
  not overwritten). PCs check a tiny "data.rev" file every 15 seconds.
- The choice of folder is stored per PC in Documents\BrocheStuff\settings.json.

FILES IT READS AND WRITES
- In the data folder: data.json (+ data.previous.json), data.rev, data.lock
  (only while saving), users.json
- <data folder>\Backups\  daily copy (last 30) and Backups\auto\
  copy every 5 minutes when data changed (last 24)
- Documents\BrocheStuff\Sheets\  PDF tool sheets the user saves
- Documents\BrocheStuff\settings.json (data folder of this PC) and
  Documents\BrocheStuff\Demo\ (the made-up demo data, when the admin opens it)
- Files the user picks himself in a normal Open / Save dialog (Excel imports,
  CNC programs to read, backups, PDF, CSV)
- Microsoft WebView2 keeps its usual browser cache for the window in the
  user's AppData folder.
No other place on the disk is used.

WHAT THE PROGRAM IS ALLOWED TO DO
The runtime only allows these native functions (nativeAllowList in the
configuration inside resources.neu): exit the app, get the Documents path,
read the COMPUTERNAME variable (for the sign-in log), show the Save and the
Choose folder dialogs, open a saved file or the data folder with its default
program, and read / write / copy / delete / list files and create folders
(used only for the folders above).
It can NOT run commands or other programs, read the clipboard, change Windows
settings, or install anything. Logging is off; developer tools are off.

CNC PROGRAMS
CNC program files (.nc, .tap, .h, .mpf ...) are only READ as text to list the
tool numbers. The program never writes, changes or sends anything to a CNC
machine.

CHECKING
- The SHA-256 of each file is in SHA256SUMS.txt / SHA256SUMS-downloads.txt; the files can be uploaded to
  VirusTotal or scanned with your antivirus.
- Unsigned programs make Windows SmartScreen show "Windows protected your PC";
  this is expected for software without a paid code-signing certificate.
- The source is public: https://github.com/achrxf/BrocheStuff

EN BREF (FRANÇAIS)
Programme hors ligne : aucune connexion Internet. Installation pour
l'utilisateur seul (%LOCALAPPDATA%\Programs), sans droit administrateur ;
seules les entrées habituelles de désinstallation dans HKCU. Comptes avec mot
de passe (PBKDF2). Données dans Documents\BrocheStuff ou dans un dossier réseau
choisi par l'admin. Serveur local limité à 127.0.0.1 avec jeton à usage
unique. Les programmes CN sont seulement lus, jamais envoyés à une machine.
Pour le désinstaller : Paramètres Windows > Applications > BrocheStuff.
